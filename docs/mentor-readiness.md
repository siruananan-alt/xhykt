# 带教老师登记转正达标线

「我的带教」每位学员卡片新增「登记转正达标线」按钮。老师可在当前页选择人工达标项目，一次保存数值、备注和结论；保存后更新卡片达标条数。学员详情也提供登记入口。

服务端保留 `adminSetReadiness` 接口，允许管理员和导师调用，并在写入、修改、清除之前校验导师与学员归属。学习达标保持系统判定，转正审批保持管理员权限，登记人和时间沿用原有留痕字段。

后端以最新线上备份为基础，运行 `scripts/prepare-mentor-readiness-function.cjs <backup> <staging>` 后上传整个 staging 目录的压缩包；不修改云端环境变量。版本标记为 `b20261019-mentor-readiness-v1`。
