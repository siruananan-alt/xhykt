# 强制解锁开关修复

2026-10-18：原开关已能保存配置并控制课程视频地址下发，但关卡列表/详情的 `levelUnlocked` 与服务器任务提交的 `levelUnlockedFor` 均无条件检查上一关，导致关闭后仍有锁定。

前后端统一为：`enforceGate === true` 时，第一关开放，后续关卡按上一关是否完成判断；关闭时所有有效关卡可进入和提交任务。观看与任务提交继续遵守各自权限、截图要求和本关先练后考规则，不自动通过任何关卡。

看板原先无条件显示“所有任务卡提交入口锁死”，现改为按开关状态和实际首个练习关卡的解锁结果提示，关闭时明确显示“不限制进入后续关卡”。

开关写入成功后，前端使用 `adminSetSetting` 保存响应中的服务端状态回填，避免读刷新失败后用旧状态覆盖已成功的操作。服务端代码只改解锁策略，保持设置写入、鉴权和历史数据不变；排查与验收未切换生产环境的开关值。

云函数发布：先下载最新代码，运行 `scripts/prepare-gate-function.cjs <backup> <staging>`，再从 staging 目录执行代码更新，保留现有配置和密钥。版本标记 `b20261018-gate-switch-v1`。
