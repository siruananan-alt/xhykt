# 每关练习教学视频

管理端「闯关总览 → 关卡教学视频」包含第四课流量一站式入门（1 个位置）、高导粉获客秘籍（3 个位置），其他有练习环节的关卡各 1 个位置。每个位置可独立上传、替换或移除 MP4，单个文件上限 2GB。学员在关卡详情的「练」区、任务卡上方观看，可暂停、拖动进度、调节音量及全屏。第四课的视频嵌入现有考区块内，不新增区块或通关要求。旧单个视频配置兼容为位置 1；移除中间视频不改变其他视频编号。观看不写学习通过记录，也不代替任务卡审核。

复用已有三路并发、5MB 分片和重试的 COS 上传器。教学视频使用独立接口和随机对象名；成功合并且 HEAD 大小核对后，才写入 `data/settings.json` 的 `practiceVideos[levelId][slot]`。替换失败保留旧视频。中止上传仅取消对应 multipart 会话；移除仅取消发布映射，历史文件保留以免破坏已打开的播放器。存储读权限沿用现有课程视频方案，关卡未解锁时服务端不向学员下发视频地址。

后端扩展源码：`functions/etrain-api/practice-video.js`。发布前下载线上云函数备份，再用 `scripts/prepare-practice-function.cjs <backup> <staging>` 准备完整代码包。脚本检查唯一锚点，避免套用到不兼容的源码。仅更新函数代码，不覆盖运行配置、环境变量和现有学习数据。版本标记：`b20261018-practice-video-v2`。

验证：`node --test tests/*.test.cjs`，覆盖权限、大小、分片合法性、替换失败保留旧视频、取消上传、移除映射、关卡过滤及前端上传接口接线。
