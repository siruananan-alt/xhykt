# 学习便签墙

入口：三端顶部「便签墙」，页面 `/app/pages/community.html`。

支持发布 1～500 字彩色便签、心得/提问/分享/加油分类、搜索内容或姓名、全部/我的、最新/最多点赞、分页、点赞及取消。作者可编辑和删除自己的便签；管理员可删除全部便签并设为精选。登录后的学员、导师、管理员均可查看全部便签。未登录显示原有登录提示，不展示内容。

新页面沿用现有登录守卫和 liveApi。便签接口重新读取账号表，以当前数据库角色鉴权，不信任请求中的姓名、角色、作者或权限。正文仅按文本渲染。便签每 30 秒在页面可见且没有操作或弹窗时刷新，也支持手动刷新；本期没有 WebSocket 或多人同时编辑。

## 纸质便签布局

与站点一致的白色底面、极浅绿色点阵背景、小尺寸彩色便签、稳定错落排布与轻微倾斜、右上折角。底部浮动工具栏集中搜索、筛选、重置与发布；编辑、删除和精选收进便签「···」菜单。正文直接在便签上完整展示，不再打开详情框。小手掌工具开启后支持鼠标或触摸拖动整面画布，方向键也可移动，Escape 退出拖动。导航与工具栏固定不动；重置按钮恢复原位。拖动仅改变当前浏览位置，不保存到后台，也不会移动单张便签或产生业务写入。本期没有缩放功能。

发布弹窗只保留正文、字数、颜色及取消/发布，分类折叠为可选项。保留现有 500 字上限及五种颜色，兼容此前内容。手机便签单列排列，弹窗控制键和底部栏均保持在屏幕范围内。

## 后台

新增模块 `functions/etrain-api/community.js`；新动作 `communityList/Create/Edit/Delete/Like/Pin`。接入点由 `scripts/prepare-community-function.cjs` 在**刚下载的最新云函数备份**上增量添加。

COS 独立命名空间 `data/community/`：

- `posts/<id>.json`：原始内容及发布者快照，永久保存。
- `edits/<id>/<time-random>.json`：不可变修改记录。按服务端时间及唯一后缀取最新版本。
- `deleted/<id>.json`：删除标记。列表永远过滤该便签，编辑不会将其恢复。
- `likes/<id>/<sha256-wid>.json`：每个用户独立的点赞对象，存在即已赞；取消点赞删除自己的对象。
- `pins/<id>.json`：置顶标记。

发布、修改和不同用户点赞使用独立对象，不覆盖全局 JSON 表。删除便签不销毁原文和修改历史。列表遍历 COS 分页，读取每张可见便签的原文及最新修改，不读取历史正文。返回每页 24 张。当前实现适合内部小规模社区；数量增长后可增加独立索引或数据库查询，避免每次筛选扫描全部便签。

不新增用户、学习、任务、转正达标线写入，不改变现有业务表。

## 验证

`node --test tests/*.test.cjs`：含便签多人发布、幂等点赞、对象分页、权限、历史保留、筛选、输入验证。

工作区 `_tools/verify-community.cjs`：真实云函数与内存对象存储隔离运行，浏览器验证三端、未登录、发帖/改帖/删除/点赞/精选/搜索、手机布局及刷新持久性；不会写生产。

## 发布顺序

1. 获取并合并远端最新前端改动；下载最新云函数代码作完整备份。
2. `node scripts/prepare-community-function.cjs <备份目录> <新暂存目录>`，检查只改接线、数据读取范围和新模块。
3. 仅更新云函数代码，保留现有环境变量和密钥；下载已部署代码逐文件比对，确认 `buildTag` 为 `b20261020-community-v1`。
4. 用隔离账号验证线上 API；不使用真实学员发布测试便签。
5. 发布前端，核对三端导航、资源缓存版本和线上浏览流程。
