# 老师端课程中心

老师导航在工作台之后增加课程中心。电脑按阶段列出关卡目录，右侧显示所选关卡的学、练、考完整内容；手机改为关卡下拉选择。搜索支持关卡、课程、章节和任务名称。`mentor-courses.html?lv=L08` 可直接进入指定关卡，关卡与搜索条件随浏览器前进、后退恢复。

内容沿用现有 courses、levels、taskDefs、taskShots、practiceVideos 配置。展示课程章节和视频、课件、只读测验题目/选项/正确答案、练习要求、截图要求、考核要求与教学示范视频。缺少配置明确提示，未配置的新要求不自行编造。

导师与管理员可访问，所有关卡可预览；学员仍受现有角色守卫与解锁规则保护。课程预览使用独立播放器，暂停、倍速与全屏均由媒体控件处理；关闭或离开时停止并释放媒体，不发送学习、任务、评分或审核写请求。老师通过 PDF 阅读器查看课件时只保存固定来源和关卡引用，返回时校验真实角色及课程归属，不接受任意返回网址。原有学员阅读流程保持兼容。

服务端沿用 data 接口，将新页加入现有导师十表读取范围，不增加存储表或写接口。发布时先备份最新云函数，再运行 `scripts/prepare-mentor-courses-function.cjs <backup> <staging>`，上传 staging 全部文件；版本 `b20261019-mentor-courses-v1`。

验证：12关、不同环节组合、空课程、三示范视频、测验答案、任务搜索、链接/历史、PDF返回、手机布局、未登录/学员/管理员权限，以及真实前端接线与隔离后端的只读请求检查。运行 `node --test tests/*.test.cjs` 和 `node ../_tools/test-mentor-courses-ui.js`；后者默认完全隔离，设置 VERIFY_BASE 可验证正式静态页面，后端请求仍拦截到内存存储。
